# Open Call for Pilot Projects

SNOWCOP is preparing an open call for pilot projects that turn information about snow and ice into practical applications for water management.

## Application documents

The final application package will be available here when the call opens:

- Call text and guide for applicants.
- Application template.
- Budget template and required declarations.

Please use the documents published for this call. The final guidelines will specify eligibility, evaluation criteria, required attachments and submission conditions.

## How to apply when the call opens

1. Read the published call guidelines and check that your organisation and proposed activities are eligible.
2. Complete the application documents using the published templates.
3. Send the completed application to **earth.observation@eurac.edu**, using the subject line below.
4. Attach every document required by the final guidelines. Include your organisation name, project title and contact person's name in the email.
5. Submit before the published deadline and retain your sent message and any receipt confirmation.

**Planned email subject:** `SNOWCOP Open Call - Application - [Organisation name]`

Submission is not open yet. The instructions above describe the planned email route; the final published call guidelines will govern submissions.
